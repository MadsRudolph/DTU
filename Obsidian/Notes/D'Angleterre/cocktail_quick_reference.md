# Hotel D'Angleterre - Cocktail Quick Reference
*For tomorrow's Christmas event*

## 🎯 THE PATTERN METHOD (Memorize This First!)

### **The 4 cl. Rule**: Almost EVERYTHING uses 4 cl. base spirit
- Exceptions: Dark & Stormy (3 cl), Russians (3 cl), French Connection (4+4)

### **Build Method Pattern**:
1. **Ice first** (always!)
2. **Spirit** (4 cl unless noted)
3. **Citrus/modifier** (if any)
4. **Top with mixer**
5. **Garnish** (almost always citrus)

## ⚡ SPEED DRILL - Test Yourself!

### "Someone orders a...what do I do?"

**Moscow Mule?** → ROCKS glass, 4 cl vodka, juice 2 limes (dump one in), Ginger Beer, lime garnish

**White Russian?** → Lowball, 3-3-3 (vodka-Kahlua-milk)

## 🎓 MEMORY TRICKS

### Glass Selection:
- **Default = Highball** (most drinks)
- **Rocks = "Stormy" + "Mule"** (the two ginger beer drinks with rum/vodka)
- **Lowball = Russians + French Connection + Virgin Bramble + Espresso Tonic**
- **Special = Aperol (wine) + Virgin Mimosa (champagne)**

### Citrus Patterns:
- **Lime garnish** = Vodka drinks, Gin Tonic, Cuba Libre, Stormy, Mule
- **Lemon garnish** = Collins drinks, Whiskey Highball
- **Orange garnish** = Aperol Spritz

### The "Squeeze 3 limes" Club:
- GT (Gin Tonic)
- Cuba Libre
- Both squeeze 3 lime wedges into the drink!

### Ginger Beer Gang (3 drinks):
- Dark & Stormy (rum)
- Moscow Mule (vodka)
- Shirley Temple (mocktail, but uses Ginger Ale)
