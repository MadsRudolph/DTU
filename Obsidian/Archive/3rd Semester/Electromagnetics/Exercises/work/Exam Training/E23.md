## Q1 — Propagation Constant $\gamma$

Which expression is correct for the propagation constant $\gamma$ of a transmission line with per-unit-length parameters $R', L', G', C'$?

### Theory  
The general propagation constant of a transmission line is:

$$
\gamma = \alpha + j\beta = \sqrt{(R' + j\omega L')(G' + j\omega C')} .
$$

This arises from solving the telegrapher’s equations and includes both conductor losses ($R'$) and dielectric losses ($G'$).

Lossless case:

$$
R' = 0,\quad G' = 0 \quad\Rightarrow\quad \gamma = j\omega\sqrt{L'C'} .
$$

### Answer Choices  
- [ ] $\sqrt{\dfrac{G' + j\omega C'}{R' + j\omega L'}}$  
- [x] $\sqrt{(R' + j\omega L')(G' + j\omega C')}$  
- [ ] $\sqrt{\dfrac{R' + j\omega L'}{G' + j\omega C'}}$  
- [ ] $\sqrt{(G' + j\omega L')(R' + j\omega C')}$

## Q2 — Phase Velocity Expression

Which expression gives the phase velocity $u_p$ of a wave?

### Theory  
For a wave of the form $\exp(j(\omega t - \beta z))$, the phase is constant when:

$$
\omega t - \beta z = \text{const}.
$$

Taking the derivative gives:

$$
u_p = \frac{\omega}{\beta}.
$$

### Answer Choices  
- [ ] $\dfrac{\partial \beta}{\partial \omega}$  
- [ ] $\omega\beta$  
- [ ] $\beta/\omega$  
- [x] $\omega/\beta$

## Q7 — TL Length Such That $\Gamma_A = \Gamma_B$

![[Q7png.png]]
Given $\Gamma_B = 0.13\angle 30^\circ$, find TL length $\ell$ such that $\Gamma_A = \Gamma_B$.

### Theory  
Reflection coefficient transforms along a TL as:

$$
\Gamma_A = \Gamma_B e^{-j2\beta \ell}.
$$

To satisfy $\Gamma_A = \Gamma_B$:

$$
e^{-j2\beta \ell} = 1
\quad\Longrightarrow\quad
2\beta\ell = 2\pi n.
$$

Fundamental nonzero solution:

$$
\ell = \frac{\lambda}{2}.
$$

### Answer Choices  
- [ ] $\lambda/8$  
- [ ] $\lambda/4$  
- [x] $\lambda/2$  
- [ ] $3\lambda/4$

## Q13 — Finding Γ_L from Γ_A 

## Problem Setup

**Circuit:**
![[Q13.png]]

**Given:**

- Γ_A = 0.539∠166° (observed at plane A, the input)
- Z₀ = 75 Ω
- ℓ = 0.3λ

**Find:** Γ_L at plane B (the load)

---

## Solution

### Step 1: Identify the Direction

We're going **FROM plane A (input) TO plane B (load)**

Direction: **Input → Load** (toward the load)

### Step 2: Choose the Correct Formula

For propagating Gamma from **input toward load**, we use:

$$\boxed{\Gamma_L = \Gamma_A \cdot e^{+j2\beta\ell}}$$

**Why the positive sign?**

- The general relation is: Γ_input = Γ_load × e^(-j2βℓ)
- Solving for Γ_load: Γ_L = Γ_A × e^(+j2βℓ)
- We're "undoing" the phase rotation to find the load

### Step 3: Calculate the Phase Shift

$$2\beta\ell = 2 \cdot \frac{2\pi}{\lambda} \cdot \ell = \frac{4\pi\ell}{\lambda}$$

$$2\beta\ell = 4\pi \times 0.3 = 1.2\pi \text{ radians} = 216°$$

### Step 4: Apply the Formula

$$\Gamma_L = \Gamma_A \cdot e^{+j216°}$$

$$\Gamma_L = 0.539\angle166° \times e^{+j216°}$$

**In polar form, multiplication means:**

- Magnitudes multiply: 0.539 × 1 = 0.539 ✓
- Angles add: 166° + 216° = 382°

$$\Gamma_L = 0.539\angle382°$$

**Normalize the angle (subtract 360°):**

$$\Gamma_L = 0.539\angle22° \quad \checkmark$$

---

### Answer choices
- [ ] $0.419\angle -12^\circ$  
- [ ] $0.832\angle 178^\circ$  
- [ ] $0.238\angle 45^\circ$  
- [x] $0.539\angle 22^\circ$  

---

## Verification with TLine.m

```matlab

Z0 = 75;
len = 0.3;  % in wavelengths

% Find load using TLine

% Display result
fprintf('Γ_L = %.3f∠%.0f°\n', abs(r.Gamma_L), rad2deg(angle(r.Gamma_L)));
% Output: Γ_L = 0.539∠22°
```

---

## Common Mistakes to Avoid

### ❌ Wrong: Using negative phase shift

```
Γ_L = Γ_A × e^(-j216°)  ← WRONG!
= 0.539∠(166° - 216°) 
= 0.539∠(-50°)  ← This gives the wrong answer!
```

**Why it's wrong:** The negative phase is for going **away from load** (load → input), not toward it.

### ❌ Wrong: Forgetting to normalize angle

```
Γ_L = 0.539∠382°  ← Correct magnitude and raw angle
```

**Why incomplete:** While technically correct, angles should be in (-180°, 180°] or [0°, 360°) **Normalized:** 382° - 360° = 22° ✓

---

## Direction Reference Table

|**Going...**|**Formula**|**Phase Sign**|
|---|---|---|
|Load → Input (away)|Γ_input = Γ_load × e^(-j2βℓ)|**Negative**|
|Input → Load (toward)|Γ_load = Γ_input × e^(+j2βℓ)|**Positive**|

**Memory aid:**

- Moving **away** from load → angle **decreases** (negative)
- Moving **toward** load → angle **increases** (positive)

---

## Step-by-Step Visual

```
Plane A (input)              Plane B (load)
    ↓                             ↓
Γ_A = 0.539∠166°     →→→     Γ_L = ?
                  ℓ = 0.3λ

Phase change going A → B:
166° → (+216°) → 382° → 22° (normalized)
     phase       raw    final
     shift       angle  angle
```

---
## Summary

**The key insight:**

1. **Direction matters!** Input → Load needs **+** phase shift
2. **Calculate phase:** 2βℓ = 4π(ℓ/λ) = 216°
3. **Add angles:** 166° + 216° = 382° = 22° (mod 360°)
4. **Magnitude stays same:** 0.539 (lossless line)

**Final Answer:** Γ_L = **0.539∠22°** ✓

## Q14 — Load Impedance from Reflection Coefficient (COMPLETE)

## Problem Setup

**Given from Q13:**

- Γ_L = 0.539∠22° (found in Q13)
- Z₀ = 75 Ω

**Find:** Z_L (load impedance)

---

## Solution

### Step 1: Write the Formula

The relationship between impedance and reflection coefficient:

$$\boxed{Z_L = Z_0 \cdot \frac{1 + \Gamma_L}{1 - \Gamma_L}}$$

This is the **inverse** of the reflection coefficient formula.

### Step 2: Convert Γ_L to Rectangular Form

We have: Γ_L = 0.539∠22°

Convert to rectangular (a + jb) form:

```
Γ_L = |Γ_L| · (cos θ + j sin θ)
    = 0.539 · (cos 22° + j sin 22°)
    = 0.539 · (0.9272 + j 0.3746)
    = 0.4998 + j0.2019
```

**Result:** Γ_L = 0.4998 + j0.2019

### Step 3: Calculate Numerator (1 + Γ_L)

```
1 + Γ_L = 1 + (0.4998 + j0.2019)
        = (1 + 0.4998) + j0.2019
        = 1.4998 + j0.2019
```

**Numerator:** 1 + Γ_L = 1.4998 + j0.2019

### Step 4: Calculate Denominator (1 - Γ_L)

```
1 - Γ_L = 1 - (0.4998 + j0.2019)
        = (1 - 0.4998) - j0.2019
        = 0.5002 - j0.2019
```

**Denominator:** 1 - Γ_L = 0.5002 - j0.2019

### Step 5: Divide Complex Numbers

To divide complex numbers, multiply numerator and denominator by the complex conjugate of the denominator.

**Conjugate of denominator:**

```
(0.5002 - j0.2019)* = 0.5002 + j0.2019
```

**Multiply numerator by conjugate:**

```
(1.4998 + j0.2019) × (0.5002 + j0.2019)
= 1.4998×0.5002 + 1.4998×j0.2019 + j0.2019×0.5002 + (j0.2019)×(j0.2019)
= 0.7502 + j0.3028 + j0.1010 + j²(0.0408)
= 0.7502 + j0.4038 - 0.0408     (since j² = -1)
= 0.7094 + j0.4038
```

**Multiply denominator by conjugate:**

```
(0.5002 - j0.2019) × (0.5002 + j0.2019)
= 0.5002² + 0.2019²
= 0.2502 + 0.0408
= 0.2910
```

**Division result:**

```
(1 + Γ_L)/(1 - Γ_L) = (0.7094 + j0.4038)/0.2910
                     = 0.7094/0.2910 + j(0.4038/0.2910)
                     = 2.438 + j1.387
```

### Step 6: Multiply by Z₀

```
Z_L = Z₀ × (1 + Γ_L)/(1 - Γ_L)
    = 75 × (2.438 + j1.387)
    = 75×2.438 + j(75×1.387)
    = 182.85 + j104.03 Ω
```

### Step 7: Round to Match Answer Format

```
Z_L ≈ 183 + j104 Ω
```

---

## Answer

✅ **Z_L = (183 + j104) Ω** (Option A)

---

## Alternative Method: Using Polar Form

Sometimes it's easier to work in polar form:

### Step A: Convert to Polar

```
1 + Γ_L = 1.4998 + j0.2019
|1 + Γ_L| = √(1.4998² + 0.2019²) = 1.5133
∠(1 + Γ_L) = arctan(0.2019/1.4998) = 7.67°

1 - Γ_L = 0.5002 - j0.2019
|1 - Γ_L| = √(0.5002² + 0.2019²) = 0.5394
∠(1 - Γ_L) = arctan(-0.2019/0.5002) = -22.00°
```

### Step B: Divide in Polar Form

```
(1 + Γ_L)/(1 - Γ_L) = (1.5133∠7.67°)/(0.5394∠-22.00°)
                     = (1.5133/0.5394)∠(7.67° - (-22.00°))
                     = 2.805∠29.67°
```

### Step C: Multiply by Z₀

```
Z_L = 75 × 2.805∠29.67°
    = 210.4∠29.67° Ω
```

### Step D: Convert Back to Rectangular

```
Z_L = 210.4(cos 29.67° + j sin 29.67°)
    = 210.4(0.8686 + j 0.4954)
    = 182.7 + j104.3 Ω
    ≈ 183 + j104 Ω ✓
```

## Q15 — Wavelength in Coax

### Problem Statement

An antenna has an input impedance of $Z_L = (142 + j42.5)\ \Omega$ and shall be matched to a system based on coaxial cables of $Z_0 = 75\ \Omega$. The circuit works at $f = 1550$ MHz. A single-stub tuner with a short-circuited stub is used. The dielectric insulator between the conductors of the coaxial cables is lossless and non-magnetic with $\varepsilon_r = 2.1$.

**What is the wavelength in the coaxial cables?**

### Given Values

|Parameter|Value|
|---|---|
|$Z_L$|$(142 + j42.5)\ \Omega$|
|$Z_0$|$75\ \Omega$|
|$f$|$1550\ \text{MHz}$|
|$\varepsilon_r$|$2.1$|

### Theory

Phase velocity: $$ v_p = \frac{c_0}{\sqrt{\varepsilon_r}} $$ Wavelength: $$ \lambda = \frac{v_p}{f} = \frac{c_0}{f\sqrt{\varepsilon_r}} $$

### Solution

$$ \lambda = \frac{2.998 \times 10^8}{1550 \times 10^6 \times \sqrt{2.1}} = \frac{2.998 \times 10^8}{2.246 \times 10^9} = 0.1335\ \text{m} = 13.3\ \text{cm} $$

### MATLAB Solution

```matlab
c0 = 2.998e8;
f = 1550e6;
eps_r = 2.1;

lambda = c0 / (f * sqrt(eps_r));
fprintf('λ = %.2f cm\n', lambda*100);
% Output: λ = 13.35 cm
```

### Answer

✅ **λ = 13.3 cm** (rounded from 13.35 cm)

### Answer Choices

- [ ] $9.21\ \text{cm}$
- [ ] $19.4\ \text{cm}$

## Q16 — Transmission Line Length $d$

### Problem Statement

An antenna has an input impedance of $Z_L = (142 + j42.5)\ \Omega$ and shall be matched to a system based on coaxial cables of $Z_0 = 75\ \Omega$. A single-stub tuner with a short-circuited stub is used.

**What is the correct length $d$ of the transmission line between M and $Z_L$?**

### Given Values

|Parameter|Value|
|---|---|
|$Z_L$|$(142 + j42.5)\ \Omega$|
|$Z_0$|$75\ \Omega$|
|$\lambda$|$13.3\ \text{cm}$ (from Q15)|

### Theory

1. Normalize load: $$ z_L = \frac{Z_L}{Z_0} $$
2. Convert to admittance: $$ y_L = \frac{1}{z_L} = g_L + jb_L $$
3. Solve for $t = \tan(\beta d)$ to reach $g = 1$ circle: $$ t^2(g_L - b_L^2 - g_L^2) + 2b_L t + (g_L - 1) = 0 $$
4. Convert electrical length to physical: $$ d = \frac{\arctan(t)}{360°} \times \lambda $$

### Manual Solution

$$z_L = \frac{142 + j42.5}{75} = 1.893 + j0.567$$ $$y_L = \frac{1}{1.893 + j0.567} = 0.485 - j0.145$$ Solving quadratic: $t = 2.264 \Rightarrow \beta d = 66.15°$ $$d = \frac{66.15°}{360°} \times 13.3\ \text{cm} = 2.45\ \text{cm} = 24.5\ \text{mm}$$

### 🚀 MATLAB Solution Using StubMatch.m

**This is the recommended approach for exams!**

5. Gives **both** solutions (there are always 2)
6. Converts to physical lengths (mm, cm, m)
7. Verifies the match

## Q17 — Stub Length $\ell$

### Problem Statement

An antenna has an input impedance of $Z_L = (142 + j42.5)\ \Omega$ and shall be matched to a system based on coaxial cables of $Z_0 = 75\ \Omega$. A single-stub tuner with a **short-circuited stub** is used.

**What is the correct length $\ell$ of the stub?**

### Given Values

|Parameter|Value|
|---|---|
|$Z_L$|$(142 + j42.5)\ \Omega$|
|$Z_0$|$75\ \Omega$|
|$\lambda$|$13.3\ \text{cm}$ (from Q15)|
|$d$|$24.5\ \text{mm}$ (from Q16)|

### Theory

At match point: $$ y_M = 1 + jb_M $$ For a short-circuited stub: $$ Z_{\text{stub}} = jZ_0 \tan(\beta\ell) $$ Admittance: $$ y_{\text{stub}} = -j\cot(\beta\ell) $$ Matching condition (susceptance cancellation): $$ b_M + b_{\text{stub}} = 0 \implies \cot(\beta\ell) = b_M $$

### Manual Solution

## Q26 — Material Classification from Loss Tangent

> A material has conductivity $\sigma = 0.01~\text{S/m}$ and real relative permittivity $\varepsilon_r = 8$.  
> How is the material classified at a frequency of $5~\text{GHz}$?

**Answer options:**

- [ ] Good conductor
- [ ] Perfect electric conductor
- [x] Good insulator
- [ ] Perfect dielectric insulator

---

### Solution

Use the **`lossy_media()`** function from [[Exercise 13]]:

```matlab

```

Or with a descriptive name:

```matlab

```

**Function Parameters:**

- `epsilon_r = 8` (εᵣ)
- `sigma = 0.01` S/m
- `freq = 5e9` Hz (5 GHz)
- `mu_r = 1` (optional, non-magnetic)
- `name = 'Q26_Material'` (optional)
---

### Theory

For a linear isotropic medium with conductivity $\sigma$ and permittivity $\varepsilon = \varepsilon_r\varepsilon_0$, the **loss tangent** is:

$$ \tan\delta = \frac{\sigma}{\omega\varepsilon} = \frac{\sigma}{2\pi f \varepsilon_r\varepsilon_0} $$

**Manual Calculation:**

$$ \tan\delta = \frac{0.01}{2\pi \times 5\times10^9 \times 8 \times 8.854\times10^{-12}} = \frac{0.01}{2.224} \approx 4.5 \times 10^{-3} $$

**Classification Heuristics:**

- $\tan\delta \ll 1$ (< 0.1) → **Low-Loss Dielectric** (good insulator)
- $\tan\delta \gg 1$ (> 10) → **Good Conductor**
- $0.1 < \tan\delta < 10$ → **Quasi-Conductor**

**Idealized Limits:**

- Perfect electric conductor: $\sigma \to \infty$
- Perfect dielectric: $\sigma = 0$ (or $\tan\delta = 0$)

**Result:**  
Since $\tan\delta = 0.0045 \ll 1$, the material behaves as a **good insulator** (lossy dielectric with small loss).

---

### Physical Interpretation

At $f = 5~\text{GHz}$:

- **Wavelength** ≈ 1.4 cm (millimeter wave range)
- **Phase velocity** ≈ 0.47c (47% speed of light due to εᵣ = 8)
- **Attenuation** ≈ 1 Np/m means signal drops to 37% after 1 meter
- **Impedance** ≈ 133 Ω (mostly resistive, very small reactive component)

The displacement current ($j\omega\varepsilon E$) dominates over the conduction current ($\sigma E$) by a factor of ~222, confirming dielectric behavior.

## Q32 — Reflected Power Fraction

For the same incidence as above, how much of the incident power is reflected?

### Theory  

For each polarization we use the Fresnel coefficients:

- TE:

$$
\Gamma_{\text{TE}} = 
\frac{ \eta_2 \cos\theta_i - \eta_1 \cos\theta_t }
     { \eta_2 \cos\theta_i + \eta_1 \cos\theta_t },
$$

- TM:

$$
\Gamma_{\text{TM}} =
\frac{ \eta_2 \cos\theta_t - \eta_1 \cos\theta_i }
     { \eta_2 \cos\theta_t + \eta_1 \cos\theta_i },
$$

where $\eta_k$ is the intrinsic impedance of medium $k$.  
The **power reflectance** for each polarization is

$$
R_{\text{TE}} = |\Gamma_{\text{TE}}|^2,\qquad
R_{\text{TM}} = |\Gamma_{\text{TM}}|^2.
$$

Because the incident wave is elliptically polarized (a mix of TE and TM), its power is split between TE and TM components. The **total reflected power fraction** is the weighted sum of the two reflectances, based on how much of the incident field is TE vs TM.

## Q33 — Brewster Angle for This Wave

For the same interface, at what angle of incidence is the magnitude of the **reflected wave** equal to zero?

### Theory  

- A **Brewster angle** exists only for **TM polarization** if both media are non-magnetic:

$$
\tan\theta_B = \sqrt{\frac{\varepsilon_2}{\varepsilon_1}}.
$$

Here $\varepsilon_2 = 4\varepsilon_1 \Rightarrow \theta_B \approx 63.4^\circ$.  

However, our incident wave is **not purely TM**; it is elliptically polarized (mixed TE and TM).  
The TE component **always** has a non-zero reflection coefficient at any finite angle.  

Therefore, the **total reflected field** (sum of TE and TM reflected components) can never be strictly zero for any incidence angle.

### Answer Choices  

- [ ] $14^\circ$  
- [ ] $76^\circ$  
- [ ] $30^\circ$  
- [x] The angle does not exist

## Q36 — Current in a Solenoid from Measured $B$

A solenoid is filled with air and consists of $N = 200$ windings.

What is the current through the windings?

### Theory  

For a long solenoid (air core):

$$
B = \mu_0 n I,
\qquad n = \frac{N}{\ell}.
$$

Thus

$$
I = \frac{B}{\mu_0 n}
= \frac{B \ell}{\mu_0 N}.
$$

## Q37 — Self-Inductance of the Solenoid

Using the same solenoid as in Q36, what is its (self-)inductance?

### Theory  

The inductance of a long solenoid is

$$
L = \mu_0 \frac{N^2 A}{\ell},
$$

where  

- $N$ is the total number of turns,  
- $A$ is the cross-sectional area:

$$
A = \pi \left(\frac{d}{2}\right)^2,
$$

- $\ell$ is the solenoid length.  

Insert $N, d, \ell$ (in meters) and $\mu_0$ to obtain $L$ in henries.

### Answer Choices
