## Q1 — Friktion i driftspunkt *(T4)*

**Hvad spørges om:** Find friktionskoefficienten $B$ i driftspunktet for en motor der driver et skateboard. Givet $K_t=0.035$, $R=0.05$, $r=0.05$, $G=3.2$, driftspunkt $\dot{x}_0=3$ m/s, $I_0=8.5$ A.

**Metode:** I steady state er integrator-input = 0 → motormoment balancerer friktionsmoment: $I_0 K_t = B\omega_0$, hvor vinkelhastigheden fås via gearing $\omega_0=\dot{x}_0\,G/r$.

> [!formula] Momentbalance
> $$B=\frac{I_0 K_t}{\dot{x}_0\,G/r}=\frac{8.5\cdot0.035}{3\cdot3.2/0.05}=0.00155$$

```matlab hl:N
Kt=0.035; R=0.05; r=0.05; G=3.2; xdot0=3; I0=8.5;
B = I0*Kt/(xdot0*G/r);
fprintf('B = %.4g\n', B);
```

**Svar:** $\boxed{B\approx0.0016 \Rightarrow \text{Mulighed 3}}$ — mulighed 4 ($0.014$) glemmer gearing-faktoren; $57.7$ forveksler lineær/vinkelhastighed.

→ Metode: [[Steady-state-error-og-disturbance]] · [[Transfer-functions-og-poler]]

## Q2 — Linearisér dampmaskine *(T1)*

**Hvad spørges om:** Find $G(s)=\omega/a$ i driftspunktet ved 600 RPM for $J\dot{\omega}+B\omega=aK\sqrt{P-H\omega}$. $J=0.23$, $B=0.12$, $K=0.056$, $P=3\times10^5$, $H=1600$.

**Metode (linearisering i 4 trin):**
1. $\omega_0=\frac{600\cdot2\pi}{60}=62.8$ rad/s.
2. Ligevægts-$a_0=\frac{B\omega_0}{K\sqrt{P-H\omega_0}}=0.30$.
3. Taylor-linearisér $\sqrt{\cdot}$-leddet mht. $\omega$: $\frac{\partial}{\partial\omega}\big(K a\sqrt{P-H\omega}\big)=-\frac{KaH}{2\sqrt{P-H\omega_0}}$.
4. Laplace + normalisér så $s$-koefficient = 1.

> [!formula] Resultat
> $$0.23s\,\omega+0.12\omega=25\,a-0.03\,\omega \;\Rightarrow\; G(s)=\frac{25}{0.23s+0.15}=\frac{109}{s+0.65}$$

```matlab hl:N
J=0.23; B=0.12; K=0.056; P=3e5; H=1600;
w0 = 600*2*pi/60;
a0 = B*w0/(K*sqrt(P-H*w0));
num = K*sqrt(P-H*w0);                 % a-koefficient ~25
dw  = 0.5*K*a0*H/sqrt(P-H*w0);        % omega-tillægsled ~0.03
s = tf('s'); Glin = num/(J*s + B + dw);
Glin = minreal(Glin); zpk(Glin)
```

**Svar:** $\boxed{G(s)=\dfrac{109}{s+0.65} \Rightarrow \text{Mulighed 4}}$

→ Metode: [[Transfer-functions-og-poler]] · Teori: [[Lec 5 — Black-box Modelling og Linearisering]]

## Q3 — Blokdiagram-reduktion *(T2)*

**Hvad spørges om:** Find $G(s)$ for sum af to grene: øvre $=A$; nedre $=$ integrator $\frac{1}{s}$ med feedback-gain $B$.

**Metode:** Reducér nedre feedback-sløjfe, læg parallelt med øvre gren.

> [!formula] Reduktion
> $$G_L=\frac{s}{s+B},\quad G=A+G_L=\frac{A(s+B)+s}{s+B}=\frac{(1+A)s+AB}{s+B}$$

**Svar:** $\boxed{\dfrac{(1+A)s+AB}{s+B} \Rightarrow \text{Mulighed 2}}$

> [!warning] Tjek figuren
> Facit forudsætter at $\frac{1}{s}$-blokken sidder i **feedback**-grenen (ikke fremad). Hvis den er i fremadgrenen, bliver svaret $\frac{As+(1+AB)}{s+B}$ — som ikke er en mulighed. Brug figurens grenstruktur.

→ Metode: [[Blokdiagram-reduktion]]

## Q4 — TF-struktur fra step-respons *(T3/T1)*

**Hvad spørges om:** Step-responsen springer til $\approx0.4$ ved $t=0$ og stiger eksponentielt til $0.8$. Hvilken TF-struktur?

**Metode:** Et spring i $t=0$ kræver lige tæller- og nævnergrad (initialværdisætning: $y(0^+)=\lim_{s\to\infty}G(s)\ne0$). Det udelukker rene poler.

> [!formula] Initial value theorem
> $$y(0^+)=\lim_{s\to\infty}sU(s)G(s)=\lim_{s\to\infty}G(s)\ne0 \;\Rightarrow\; \deg(\text{tæller})=\deg(\text{nævner})$$
> Eksempel der passer: $G(s)=\frac{0.4s+0.8}{s+1}$ → $y(0^+)=0.4$, $y(\infty)=0.8$.

**Svar:** $\boxed{G(s)=\dfrac{b_1 s+b_0}{s+a_0} \Rightarrow \text{Mulighed 3}}$ — rene 1./2.-ordens poler ville starte i $0$.

→ Metode: [[Time-response-2nd-order]]

## Q5 — Dæmpning fra overshoot *(T3)*

**Hvad spørges om:** $G(s)=\frac{200}{s^2+2\zeta\omega_n s+\omega_n^2}$, $\omega_n=10$. Step-respons med peak $2.9$, slutværdi $2$. Find $\zeta$.

> [!formula] Overshoot → dæmpning
> $$M_p=\frac{2.9-2}{2}=0.45 \;\Rightarrow\; \zeta=\frac{-\ln M_p}{\sqrt{\pi^2+(\ln M_p)^2}}=0.25$$

```matlab hl:N
Mp = (2.9-2)/2;
zeta = -log(Mp)/sqrt(pi^2+log(Mp)^2);   % = overshoot2damping(Mp)
fprintf('zeta = %.4g\n', zeta);          % 0.246
```

**Svar:** $\boxed{\zeta\approx0.2 \Rightarrow \text{Mulighed 2}}$ (eksakt $0.246$, nærmeste mulighed).

→ Metode: [[Time-response-2nd-order]]

## Q6 — Poler/nuller fra Bode *(T7)*

**Hvad spørges om:** Magnitude starter $-5$ dB, top $+6$ dB ved $\sim10^2$, fald mod $10^4$. Fase $0°\to+30°\to-90°$. Find poler og nuller.

**Metode:** Fase **op** = zero, fase **ned** = pol. Slutfase $-90°(\#\text{poler}-\#\text{nul})$.
- Første hændelse (lav frekvens) = zero ved $\sim10$ rad/s.
- Pol ved $\sim50$ rad/s, anden pol ved $\sim1000$ rad/s.

**Svar:** $\boxed{\text{Poler }s=-50,\,-1000;\ \text{zero }s=-10}$

```matlab hl:/bode\(/
G = zpk(-10,[-50 -1000],1);   % skalér så DC matcher
bode(G); grid on
```

→ Metode: [[Bode-aflæsning]]

## Q7 — Bandwidth fra closed-loop Bode *(T7)*

**Hvad spørges om:** Closed-loop Bode med lavfrekvens $+3$ dB, resonanstop. Find bandbredde.

> [!formula] Bandbredde
> $$\text{BW}=\text{frekvens hvor }|G|\text{ er faldet }-3\text{ dB ift. lavfrekvens-asymptoten}$$
> Lavfrekvens $=+3$ dB → $-3$ dB-punktet = hvor kurven krydser $0$ dB $\approx22$ rad/s.

**Svar:** $\boxed{\text{BW}=22\text{ rad/s} \Rightarrow \text{Mulighed 2}}$

→ Metode: [[Bode-aflæsning]] · Snydeark: [[MATLAB-snydeark]] (`bandwidth`)

## Q8 — Match step ↔ Bode *(T3/T7)*

**Hvad spørges om:** Step-respons: $63\%$ efter $\sim1$ ms + hurtig svingning med periode $T\approx1.2$ ms. Hvilken Bode?

> [!formula] Tid → frekvens
> $$\text{1.-ordens knæk: } \omega=1/\tau=1000\text{ rad/s},\qquad \text{resonanstop: } \omega_n=\frac{2\pi}{T}=\frac{2\pi}{1.2\text{ ms}}=5236\text{ rad/s}$$

**Svar:** $\boxed{\text{Bode med knæk }\sim1000\text{ og top }\sim5236\text{ rad/s}}$

→ Metode: [[Bode-aflæsning]] · [[Time-response-2nd-order]]

## Q9 — P-design (PM=60°) *(T9)*

**Hvad spørges om:** Find $K_P$ for hurtigt, stabilt system med phase margin $60°$.

**Metode:** Find $\omega_c$ hvor fasen er $-180°+60°=-120°$. Aflæs $|G(\omega_c)|\approx23$ dB → $K_P=-23$ dB.

```matlab hl:/bode\(/
% find Kp så PM=60 (G aflæst fra opgavens Bode)
% ved fase=-120 grader er |G|~+23 dB  => Kp = 10^(-23/20)
Kp = 10^(-23/20);
fprintf('Kp = %.4g\n', Kp);   % 0.0708
```

**Svar:** $\boxed{K_P\approx0.06 \Rightarrow \text{Mulighed 1}}$ (eksakt $0.0708$).

→ Metode: [[Controller-design-P-PI-Lead]]

## Q10 — Lead zero-frekvens *(T10)*

**Hvad spørges om:** $G(s)=\frac{28880}{s^4+7.04s^3+1460s^2+5788s+5776}$, $\omega_c=10$, $\alpha=0.1$. Find Lead-leddets zero-frekvens.

> [!formula] Lead centreret på $\omega_c$
> $$\tau_d=\frac{1}{\omega_c\sqrt\alpha}=\frac{1}{10\sqrt{0.1}}=0.32\text{ s} \;\Rightarrow\; \omega_z=\frac{1}{\tau_d}=\omega_c\sqrt\alpha=3.16\text{ rad/s}$$

```matlab hl:N
wc=10; alpha=0.1;
taud=1/(wc*sqrt(alpha)); wz=1/taud;
fprintf('taud=%.4g, wz=%.4g\n', taud, wz);
```

**Svar:** $\boxed{\omega_z\approx3.2\text{ rad/s} \Rightarrow \text{Mulighed 2}}$

→ Metode: [[Controller-design-P-PI-Lead]]

## Q11 — P-Lead gain *(T10)*

**Hvad spørges om:** Samme $G(s)$, $\omega_c=10$, $\alpha=0.1$. Find $K_P$ i P-Lead.

**Metode:** Lead-løft ved center: $|C_d(\omega_c)|=1/\sqrt\alpha=3.2$ ($10$ dB). $K_P=1/|G(\omega_c)C_d(\omega_c)|$.

```matlab hl:/bode\(|evalfr\(/
s=tf('s'); G=28880/(s^4+7.04*s^3+1460*s^2+5788*s+5776);
wc=10; alpha=0.1; taud=1/(wc*sqrt(alpha));
Cd=(taud*s+1)/(alpha*taud*s+1);
Kp=1/abs(evalfr(G*Cd,1j*wc));
fprintf('Kp = %.4g\n', Kp);   % ~1.5
```

**Svar:** $\boxed{K_P\approx1.5 \Rightarrow \text{Mulighed 1}}$

→ Metode: [[Controller-design-P-PI-Lead]]

## Q12 — Stabilitet af P-Lead *(T8)*

**Hvad spørges om:** Bliver systemet stabilt med P-Lead fra Q11?

**Metode:** Lead løfter gain omkring center-frekvensen og forstærker en resonanstop ved $\sim40$ rad/s. Toppen kommer over $0$ dB hvor fasen er $<-180°$ → ustabilt.

```matlab hl:/nyquist\(/
nyquist(Kp*G*Cd)   % tjek omkredsning af -1
```

**Svar:** $\boxed{\text{No (ustabilt)}}$

→ Metode: [[Stabilitet-Nyquist-margins]]

## Q13 — Komplekse poler? *(T1)*

**Hvad spørges om:** $G(s)=\frac{229320}{s^3+1317s^2+23604s+2.29\times10^6}$ har 3 poler — er nogen komplekse?

**Metode:** Resonanstop i magnitude ⟹ underdæmpet polpar ⟹ komplekse poler.

```matlab hl:/roots\(/
disp(roots([1 1317 23604 2.29e6]).')   % -1300, -8.4 +/- 41i
```

**Svar:** $\boxed{\text{Yes} — s=-8.4\pm41i}$

→ Metode: [[Transfer-functions-og-poler]]

## Q14 — PI-Lead gain *(T9/T10)*

**Hvad spørges om:** Samme $G(s)$ som Q13. PI-Lead med $N_i=3$, $\alpha=0.1$, $\gamma_M=40°$. Find $K_P$.

> [!formula] Fasebudget
> $$\phi_i=-90°+\arctan N_i=-18.4°,\quad \phi_m=\arcsin\tfrac{1-\alpha}{1+\alpha}=54.9°$$
> Find $\omega_c\approx122$ rad/s hvor $\angle G=-180°+\gamma_M-\phi_m-\phi_i$, så $\tau_d,\tau_i$, så $K_P$.

```matlab hl:/bode\(|evalfr\(/
s=tf('s'); G=229320/(s^3+1317*s^2+23604*s+2.29e6);
gM=40; Ni=3; alpha=0.1;
phi_i=atand(-1/Ni); phi_m=asind((1-alpha)/(1+alpha));
phiG=-180+gM-phi_m-phi_i;
w=logspace(0,4,4e5); [~,ph]=bode(G,w); ph=squeeze(ph);
wc=w(find(ph<=phiG,1,'first'));
taui=Ni/wc; taud=1/(wc*sqrt(alpha));
CPI=(taui*s+1)/(taui*s); CD=(taud*s+1)/(alpha*taud*s+1);
Kp=1/abs(evalfr(G*CPI*CD,1j*wc));
fprintf('wc=%.4g, Kp=%.4g\n', wc, Kp);   % ~23
```

**Svar:** $\boxed{K_P\approx23 \Rightarrow \text{Mulighed 1}}$

→ Metode: [[Controller-design-P-PI-Lead]] · Snydeark: [[MATLAB-snydeark]]

## Q15 — Lead i forward vs. feedback *(T10)*

**Hvad spørges om:** Hvilken step-respons (blå = stejl med overshoot) svarer til Lead i hvilken gren?

**Metode:** Lead i **forward**-grenen differentierer reference-springet → stejlere flanke + mere overshoot. I feedback påvirker det kun loop-dynamik uden at differentiere referencen.

**Svar:** $\boxed{\text{Blå kurve = Lead i forward-grenen}}$

## Q16 — RHP-pol? *(T5)*

**Hvad spørges om:** $G(s)=\frac{5}{s^2-11.5}$. Poler i højre halvplan?

> [!formula] Faktorisering
> $$s^2-11.5=0 \Rightarrow s=\pm\sqrt{11.5}=\pm3.39 \;\Rightarrow\; \text{én pol i RHP }(+3.39)$$
> Indikator: manglende $s^1$-led + negativt konstantled ⟹ ustabil.

```matlab hl:/roots\(/
disp(roots([1 0 -11.5]).')   % -3.39, +3.39
```

**Svar:** $\boxed{\text{1 pol i RHP}}$

→ Metode: [[Stabilitet-Nyquist-margins]]

## Q17 — Nyquist-stabilitet (RHP-pol) *(T8)*

**Hvad spørges om:** Samme $G$ (1 RHP-pol) + P-lag-lead, $K_p=51$. Bliver closed-loop stabil?

**Metode:** Med $P=1$ RHP-pol skal Nyquist omkredse $(-1,0)$ **én gang mod uret** for $Z=P-N=0$. Plottet (figur-8) viser netop dette.

**Svar:** $\boxed{\text{Yes (stabilt)}}$

→ Metode: [[Stabilitet-Nyquist-margins]]

## Q18 — Stabilitet ved gain-reduktion *(T8)*

**Hvad spørges om:** Samme system, men $K_p$ reduceres fra $51$ til $1$. Stabilt?

**Metode:** At reducere $K_p$ skalerer Nyquist-kurven radialt. Mest negative reelle værdi var $-22$ → bliver $-22/51=-0.44$. Da $|-0.44|<1$ omkredses $(-1,0)$ ikke længere → RHP-polen forbliver ukompenseret → ustabilt.

**Svar:** $\boxed{\text{No (ustabilt)}}$

> [!tip] Ustabilt anlæg
> Modsat et stabilt anlæg skal du her holde gain **højt nok** — for lavt gain mister den nødvendige omkredsning. Se [[Stabilitet-Nyquist-margins]] Q12-eksemplet.

## Q19 — Disturbance-sensitivitet *(T4)*

**Hvad spørges om:** Bioreaktor med to forstyrrelser: $d_1$ (før integrator $G=0.5/s$), $d_2$ (efter $G$), $K_p=4$. Hvilken kurve svarer til $d_1$?

**Metode:**
- $d_2$ efter integrator → integrator giver uendelig DC-gain → undertrykkes fuldt → $e_{ss}=0$ (kurve B).
- $d_1$ før integrator → i steady state $u=-d_1$, fejlen $=1/K_p=1/4=25\%=-12$ dB → flad lavfrekvens ved $-12$ dB (kurve C).

**Svar:** $\boxed{\text{Kurve C}}$ ($d_1$ giver $-12$ dB stationær fejl).

→ Metode: [[Steady-state-error-og-disturbance]] · Teori: [[Lec 12 — Forstyrrelser, Sensitivitet og Pre-filtre]]
