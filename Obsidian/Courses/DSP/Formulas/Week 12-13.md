## Week 12 - Multirate Digital Signal Processing

### 12.1 Decimation (Down-sampling) [[Uge 12 - Tirsdag]]

**Definition:**
Reduce sampling rate by integer factor $M$

**Discrete-time relation:**
$$x_D[n] = x[Mn]$$

Keep every $M$-th sample, discard others

**Frequency domain effect:**
- Spectrum **compresses by factor M**
- Spectrum **replicates** at intervals of $\frac{2\pi}{M}$
- **ALIASING occurs** if signal energy exists above new Nyquist frequency

**New sampling frequency:**
$$F_s' = \frac{F_s}{M}$$

**New Nyquist frequency:**
$$F_{\max}' = \frac{F_s'}{2} = \frac{F_s}{2M}$$

**Example:**
- Original: $F_s = 8000$ Hz, Nyquist = 4000 Hz
- Decimate by $M = 2$
- New: $F_s' = 4000$ Hz, Nyquist' = 2000 Hz
- **Any frequency component above 2000 Hz will alias!**

### 12.2 Anti-Aliasing (AA) Filter Before Decimation [[Uge 12 - Tirsdag]]

**Purpose:**
Remove frequency content above new Nyquist frequency **BEFORE** decimation

**Requirements:**
- **Passband:** $0 \leq F \leq F_{\text{pass}}$ (preserve desired content)
- **Transition:** $F_{\text{pass}} < F < F_{\text{stop}}$
- **Stopband:** $F_{\text{stop}} \leq F \leq \frac{F_s}{2}$ (must attenuate)

**Critical constraint:**
$$F_{\text{stop}} \leq \frac{F_s'}{2} = \frac{F_s}{2M}$$

**Design approach (FIR LP):**
1. Choose cutoff: $\omega_c = 2\pi F_c/F_s$ where $F_c < F_s/(2M)$
2. Design FIR lowpass (windowing method)
3. Apply filter: $x_{\text{filtered}}[n] = x[n] * h_{\text{AA}}[n]$
4. Then decimate: $x_D[n] = x_{\text{filtered}}[Mn]$

**MATLAB:**
```matlab
% Design AA filter
Fc = Fs/(2*M) - transition_width;      % Cutoff below new Nyquist
wc = 2*pi*Fc/Fs;
h_AA = fir1(M_order, Fc/(Fs/2), hamming(M_order+1));

% Filter then decimate
x_filtered = filter(h_AA, 1, x);
x_decimated = x_filtered(1:M:end);     % Keep every M-th sample

% Or use decimate() which does both
x_decimated = decimate(x, M);          % Uses Chebyshev AA filter
```

### 12.3 Spectrum After Decimation

**Original spectrum:** $X(e^{j\omega})$, $\omega \in [-\pi, \pi]$

**After decimation by M:**
$$X_D(e^{j\omega}) = \frac{1}{M}\sum_{k=0}^{M-1} X\left(e^{j(\omega - 2\pi k)/M}\right)$$

**In frequency (Hz):**
- Original peaks at $F_1, F_2, \ldots$
- After decimation: peaks remain but spectrum compressed
- If $F_i > F_s'/(2) = F_s/(2M)$, then $F_i$ aliases to:
  $$F_{i,\text{alias}} = \left|F_i - k\frac{F_s}{M}\right|$$
  for appropriate integer $k$

**Example from** [[Uge 12 - Tirsdag]]:
- Signal: $F_1 = 1000$ Hz, $F_2 = 3500$ Hz
- Original $F_s = 8000$ Hz
- Decimate by $M = 2$ → $F_s' = 4000$ Hz, Nyquist' = 2000 Hz
- $F_1 = 1000$ Hz < 2000 Hz ✓ (no aliasing)
- $F_2 = 3500$ Hz > 2000 Hz ✗ (ALIASES!)
- $F_{2,\text{alias}} = |3500 - 4000| = 500$ Hz

### 12.4 Interpolation (Up-sampling) [[Uge 12 - Torsdag]]

**Definition:**
Increase sampling rate by integer factor $L$

**Zero-insertion:**
$$x_{\uparrow L}[n] = \begin{cases}
x[n/L], & n = 0, \pm L, \pm 2L, \ldots \\
0, & \text{otherwise}
\end{cases}$$

**MATLAB:**
```matlab
% Manual zero-insertion
x_upsampled = zeros(1, L*length(x));
x_upsampled(1:L:end) = x;

% Or use upsample()
x_upsampled = upsample(x, L);
```

**New sampling frequency:**
$$F_s' = L \cdot F_s$$

**Frequency domain effect:**
- Spectrum **expands by factor L** (stretches along frequency axis)
- Original spectrum in $[0, 2\pi/L]$
- **Images appear** at multiples of $2\pi/L$

### 12.5 Anti-Imaging (AI) Filter After Interpolation [[Uge 12 - Torsdag]]

**Purpose:**
Remove spectral images created by zero-insertion

**Requirements:**
- **Passband:** $0 \leq F \leq F_{\text{pass}}$ (preserve original signal)
- **Stopband:** $F_{\text{stop}} \leq F$ (remove images)

**Critical constraint:**
$$F_{\text{stop}} \geq \frac{F_s}{2}$$

where $F_s$ is the **original** sampling frequency (before interpolation).

**Design approach:**
1. Design FIR LP with cutoff at original Nyquist: $\omega_c = \pi/L$
2. **Gain factor:** Multiply by $L$ to compensate for zero-insertion
3. Apply after up-sampling

**MATLAB:**
```matlab
% Design AI filter
Fc = Fs/2;                         % Original Nyquist
wc = pi/L;                         % Digital cutoff
h_AI = L * fir1(M_order, wc/pi, hamming(M_order+1));

% Interpolate (upsample + filter)
x_upsampled = upsample(x, L);
x_interpolated = filter(h_AI, 1, x_upsampled);

% Or use interp() which does both
x_interpolated = interp(x, L);     % Uses built-in AI filter
```

### 12.6 Spectrum After Interpolation

**Original spectrum:** $X(e^{j\omega})$

**After zero-insertion:**
$$X_{\uparrow L}(e^{j\omega}) = X(e^{j\omega L})$$

Spectrum is **compressed** to $[0, 2\pi/L]$ and **repeated** $L$ times.

**After AI filtering:**
Spectral images removed, only baseband copy remains:
$$X_I(e^{j\omega}) = L \cdot X(e^{j\omega L}) \cdot H_{\text{LP}}(e^{j\omega})$$

where $H_{\text{LP}}$ is the anti-imaging filter.

### 12.7 Polyphase Decomposition

**Concept:**
Efficient implementation of multirate systems by decomposing filters into parallel branches.

**Polyphase decomposition of $H(z)$ for decimation by M:**
$$H(z) = \sum_{k=0}^{M-1} z^{-k} E_k(z^M)$$

where $E_k(z)$ are the **polyphase components**:
$$E_k(z) = \sum_{n=0}^{\lfloor (N-k-1)/M \rfloor} h[Mn + k] z^{-n}$$

**Advantage:**
- Filtering at **lower rate** (more efficient)
- Reduces computational cost by factor of $M$ for decimation

**Noble identities:**
Allow swapping of decimation/interpolation with filtering under certain conditions.

**MATLAB:**
Polyphase filtering is built into `decimate()` and `interp()` functions.

### 12.8 Combined Systems (Decimation + Interpolation)

**Rational rate change by $L/M$:**
1. **Interpolate** by $L$ (upsample + AI filter)
2. **Decimate** by $M$ (AA filter + downsample)

**New sampling frequency:**
$$F_s' = \frac{L}{M} \cdot F_s$$

**Example:**
- Convert $F_s = 8$ kHz to $F_s' = 12$ kHz
- $L/M = 12/8 = 3/2$
- Upsample by $L = 3$ → 24 kHz
- Downsample by $M = 2$ → 12 kHz

**MATLAB:**
```matlab
x_resampled = resample(x, L, M);   % Combined interpolation + decimation
```

### 12.9 Fractional Rate Change

**For arbitrary rate change:**
Use combination of integer $L$ and $M$ that approximates desired ratio.

**Example:** $F_s = 44.1$ kHz to $F_s' = 48$ kHz
$$\frac{48}{44.1} = \frac{160}{147}$$

- Interpolate by $L = 160$
- Decimate by $M = 147$

**Computational efficiency:**
Use polyphase implementation to minimize operations at high intermediate rate.

### 13.3 Common Calculation Errors

**Top 10 exam mistakes (from E19-F25 solution analysis):**

1. **Forgetting prewarping in IIR design** → Automatic fail on Problem 2
2. **Sign errors** in feedback coefficients ($-a_k$ vs $a_k$)
3. **Wrong aliasing formula** (missing factor of 2)
4. **Confusing $\omega$ (rad/sample) vs $\Omega$ (rad/s)**
5. **Using Hamming when exam asks for Hanning** (or vice versa!)
6. **Forgetting $1/N$ in inverse DFT**
7. **Not checking stability** (poles inside unit circle)
8. **Wrong ROC** for causal vs anti-causal
9. **Mixing up zeros and poles** for inverse stability
10. **Incorrect MATLAB syntax** (forgot `.` for element-wise ops)

**Prevention:**
- **Read problem statement twice** before starting
- **Label all axes** on plots (frequency in Hz or rad/sample?)
- **Check units** (Hz vs rad/s, dB vs linear)
- **Verify MATLAB output** with sanity checks

### 13.4 MATLAB Exam Tips

**Before exam:**
```matlab
% Save this as startup.m in your exam folder
clear all; close all; clc;
format compact;  % Saves screen space
set(0,'DefaultFigureWindowStyle','docked');  % Dock figures
```

**Essential commands cheat sheet:**
```matlab
% ===== Signals =====
n = 0:N-1;                    % Time index
delta = (n == 0);             % Impulse
u = (n >= 0);                 % Step

% ===== Convolution =====
y = conv(x, h);               % Linear convolution
y = filter(b, a, x);          % IIR filtering

% ===== Z-domain =====
[r,p,k] = residue(b,a);       % Partial fractions
zplane(b,a);                  % Pole-zero plot
poles = roots(a);             % Find poles
zeros = roots(b);             % Find zeros
stable = all(abs(poles)<1);   % Check stability

% ===== Frequency Response =====
[H,w] = freqz(b,a,N);         % Digital freq response
F = w*Fs/(2*pi);              % Convert to Hz
mag_dB = 20*log10(abs(H));    % Magnitude in dB

% ===== IIR Design (BLT) =====
Omega_p = 2*Fs*tan(pi*Fp/Fs); % PREWARPING!
[b,a] = butter(n,Wp,'s');     % Analog Butterworth
[bz,az] = bilinear(b,a,Fs);   % Digital filter

% ===== FIR Design (Windowing) =====
wc = 2*pi*Fc/Fs;              % Digital cutoff
h_ideal = sin(wc*(n-K))./(pi*(n-K));
h_ideal(K+1) = wc/pi;         % Fix n=0
w = hamming(M+1)';            % Window
b_fir = h_ideal .* w;         % Windowed FIR

% ===== DFT/FFT =====
X = fft(x);                   % DFT
X_shift = fftshift(X);        % Center spectrum
f = (0:N-1)*(Fs/N);           % Freq vector

% ===== Multirate =====
y = decimate(x,M);            % Decimation
y = interp(x,L);              % Interpolation
y = resample(x,L,M);          % Rational rate change

% ===== Plotting =====
stem(n,x,'filled');           % Discrete signals
plot(F,mag_dB,'LineWidth',2); % Frequency response
xline(Fc,'--r','F_c');        % Mark frequencies
grid on; xlabel('F [Hz]'); ylabel('Magnitude [dB]');
```

**Debugging tricks:**
```matlab
% Quick checks
max(x)                        % Spot outliers
sum(h)                        % DC gain (FIR)
abs(sum(h))                   % Total gain

% Verify filter worked
figure; plot(x); hold on; plot(y);
legend('Input','Output');

% Check if all-pass
H = freqz(b,a,1024);
all(abs(abs(H)-1) < 0.01)     % Should be true
```

### 13.5 Formula Quick Reference

**Absolutely must memorize:**

1. **Convolution theorem:**
   $$y[n] = x[n] * h[n] \Leftrightarrow Y(z) = X(z)H(z)$$

2. **Stability:**
   $$\text{Stable} \Leftrightarrow \text{All poles: } |p_k| < 1$$

3. **Inverse stability (minimum phase):**
   $$\text{Stable inverse} \Leftrightarrow \text{All zeros: } |z_k| < 1$$

4. **Prewarping (BLT):**
   $$\Omega = 2F_s \tan\left(\pi \frac{F}{F_s}\right)$$

5. **Nyquist:**
   $$F_s \geq 2F_{\max}$$

6. **Aliasing:**
   $$F_{\text{alias}} = F - 2(F - F_s/2)$$

7. **Frequency conversion:**
   $$\omega = 2\pi \frac{F}{F_s}$$

8. **DFT:**
   $$X[k] = \sum_{n=0}^{N-1} x[n] e^{-j\frac{2\pi}{N}kn}$$

9. **Windows:**
   - Hamming: $w[n] = 0.54 - 0.46\cos(2\pi n/M)$
   - Hanning: $w[n] = 0.5 - 0.5\cos(2\pi n/M)$
   - Blackman: $w[n] = 0.42 - 0.5\cos(2\pi n/M) + 0.08\cos(4\pi n/M)$

10. **Decimation new Nyquist:**
    $$F_{\text{Nyq,new}} = \frac{F_s}{2M}$$
