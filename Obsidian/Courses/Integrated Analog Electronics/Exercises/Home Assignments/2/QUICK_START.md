## 🆘 TROUBLESHOOTING

### "I don't see 3 pages of content!"
- Make sure you selected **main.tex** (not main_detailed.tex)
- Check that margins are 2cm (should be set automatically)
- Verify you're using the *_condensed.tex files

### "Images don't display!"
- Make sure the images folder was uploaded
- Check file paths in Overleaf match: `images/DUT.png`, etc.
- Try recompiling

### "I want even more condensed!"
- See `CONDENSING_NOTES.md` for Priority 1-5 cuts
