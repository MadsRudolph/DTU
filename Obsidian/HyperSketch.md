# HyperSketch — tablet sketches in your DTU notes

After pulling this vault on a PC, reload Obsidian and open **Settings → HyperSketch Companion**. Choose **Tailscale** or **Local Wi-Fi / LAN**, then scan the QR code with the tablet.

Keep a Markdown note open in editing mode. The tablet shows the destination note; tap **Insert** to place the cropped drawing there. There is no separate server to start.

The pad includes freehand, dashed/dotted lines, shapes/arrows, hold-to-straighten, engineering symbols, labels, select/move, undo/redo and editable drawing save/open. Use the **Hold** toggle if pauses in handwritten equations trigger unwanted straightening.

Connection settings are per-PC. Git brings the plugin and drawing assets, but does not copy the other PC's IP address or pairing key. An optional Tailscale HTTPS URL enables PWA installation; ordinary browser drawing works without installation.

Detailed setup and tool instructions: `.obsidian/plugins/hypersketch/README.md`.
