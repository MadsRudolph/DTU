# 34870 — KiCad/ngspice companion sims

One folder per source, one KiCad project per problem. Lab A's projects live
separately under `../Labs/Lab A/KiCad/` (regenerated by `../Labs/Lab A/sim/`).

- `Lecture 3/` — in-class problems 2.x (Helmholtz resonator, two-tube network)
- `Lecture 4/` — in-class problems 4.x + the slide-9 massless-piston exercise
  (`Problem_4A_…`); `Problem_4.2-4.4a_…` is problem 4.2 built with the 4.4a
  values, both analogies on one sheet
- `Problems 4 - Dynamic Microphone/` — the homework sheet (Lecture 4B):
  `Problem_4B_…` = problem 2a model, `Problem_4.1_Mic_Design` = problem 1's
  designed mic (note: *sheet* problem 1, not in-class 4.1),
  `Problem_4.2bcd_…` = problem 2b–d back-network experiments

Each project: `layout.py` regenerates the `.kicad_sch`/`.kicad_pro`/`.wbk`
(run with `~/KiCad-Autoplace/.venv/bin/python` — it has `sexpdata`), `sim.py`
runs ngspice headless via `../../ngspice_ac.py` and writes the plot PNG here
and into the vault `Images/Lecture4/`. Schematics open directly in KiCad's
simulator (the `.ac` directive is on the sheet).

Gotchas learned on the way (details in the lecture-4 note):
- component values are written with 6 significant digits — 3 was enough to
  shift a high-Q antiresonance by several percent
- never reconstruct a current from the difference of two exported node
  voltages (`wrdata` print precision); measure `i(vX)` instead
- GSOURCE rot=180 stacks C+/C− at the same x — vertical control stubs short
  through each other; use rot=0 with opposite-direction stubs
