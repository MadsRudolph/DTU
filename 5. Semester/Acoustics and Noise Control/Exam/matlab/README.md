# Doing the exam (part 1) in MATLAB

1. **Copy `EXAM.m`** and give it a name (`Exam_2024.m` for a practice run, `Exam_34840.m` on the day). Fill in your student number.
2. **One `%%` section per sub-question.** Inside it:
   - `% Given:` the numbers from the paper,
   - `% Formula:` the formula as a comment (`$$ ... $$` renders as maths in the PDF),
   - one MATLAB line per step, **without a semicolon**, so each value prints,
   - `% Answer 1.1: ...` with the final number and unit.
3. **Stuck on how to set it up?** `../toolkit/README.md` tells you which template (T01–T15) fits the question. Open it, copy the lines you need into your section, change the givens. The formula-sheets page (`../formulas/acoustics-formulas.html`) is quicker for checking a single number.
4. **Hand-in PDF:** in MATLAB type `publish('Exam_34840.m','format','pdf')` (or Publish tab → Publish). The PDF is in the `html/` folder next to the script. Open it and check that every answer shows before uploading.

Practising on an old exam: open the paper from `Obsidian/Courses/34840 …/_Learn/000 - Old exams/`, copy `EXAM.m` to `Exam_2024.m`, work through it with a timer (part 1 ≈ 2 h), publish, then compare with `Exercises/34840_Exam_2024_part1_solution.pdf`.
