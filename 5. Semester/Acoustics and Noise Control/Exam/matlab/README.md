# Doing the exam (part 1) in MATLAB

1. **Open `EXAM.mlx`** (the live script; `EXAM.m` is its plain-text source) and **Save As** a new name (`Exam_2024.m` for a practice run, `Exam_34840.m` on the day). Fill in your student number.
2. **One `%%` section per sub-question.** Inside it:
   - `% Given:` the numbers from the paper,
   - the formula in a text line (Insert → Equation, or type `$$ ... $$` in a text line),
   - one MATLAB line per step, **without a semicolon**, so each value prints next to the code,
   - `% Answer 1.1: ...` with the final number and unit.
3. **Stuck on how to set it up?** `../toolkit/README.md` tells you which template (T01–T15) fits the question. Open it, copy the lines you need into your section, change the givens. The formula-sheets page (`../formulas/acoustics-formulas.html`) is quicker for checking a single number.
4. **Hand-in PDF:** Run All (F5), then Live Editor → Export → PDF. From the command window: `export('Exam_34840.mlx','Exam_34840.pdf','Run',true)`. Open the PDF and check that every answer shows before uploading.

Practising on an old exam: open the paper from `Obsidian/Courses/34840 …/_Learn/000 - Old exams/`, save `EXAM.mlx` as `Exam_2024.mlx`, work through it with a timer (part 1 ≈ 2 h), publish, then compare with `Exercises/34840_Exam_2024_part1_solution.pdf`.
