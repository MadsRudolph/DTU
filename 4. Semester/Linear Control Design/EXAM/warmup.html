What all of it is

Every control system is one loop: measure what you got, compare it to what you wanted, correct the difference. The whole course asks one thing about that loop — does it settle, oscillate, or run away?

The five stories

Suspension → damping. Worn shocks bounce and overshoot; good shocks settle in one bounce. ζ is the shocks, ωn the spring stiffness — a stiffer spring makes the same bounce happen faster, not smaller.
Thermostat → steady-state error. A proportional heater needs a gap to keep working, so a gap always remains. An integrator keeps accumulating and can't stop until the error is exactly zero.
Shower with a long pipe → phase margin. Turn it up, nothing, turn it up more, scalding, overcorrect, freezing. Delay causes the oscillation. Phase margin is how much more delay you can take.
Broom on your palm → unstable plant. React gently and it falls. Unstable plants need aggressive control — which is why the stable gain interval flips.
Countersteering a bike → RHP zero. To go right you first steer left. The system moves the wrong way first.

How to open, whatever they ask

Block diagram“Forward path over one plus the loop gain — and the loop gain is everything I meet going once around the loop.”
Steady-state error“I start from E = R over one plus L, apply the final value theorem, then count integrators.”
Margins“Both margins ask the same question — how far is the loop from the minus-one point — one in gain, one in phase.”
Second order“Zeta sets the shape, omega-n only sets how fast it happens.”
Controller design“It's a phase budget. The plant gives what it gives, the lead pays in, the PI costs.”
S and T“The junction defines e = r minus y. Divide by r and S = 1 minus T.”

When you get stuck

  1. Name the structure you see.
  2. Name the rule that applies.
  3. Write the general form.
  4. Then substitute numbers.

Narrate it. Examiners mark reasoning — a spoken method scores where a silent wrong number does not. Silence is the only real mistake.

Free credit, any time“Let me sanity-check — if I set H to zero this should collapse to the plain loop, and it does.”
