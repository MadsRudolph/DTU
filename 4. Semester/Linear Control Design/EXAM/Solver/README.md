# LCD1 Solver

Offline solver for DTU 34722 Linear Control Design 1 multiple-choice exam (2-June-2026).

## Install
```
cd "4. Semester/Linear Control Design/EXAM/Solver"
pip install -r requirements.txt
```

## Run
```
python run.py
```

## Test
```
pytest
```

See `docs/superpowers/specs/2026-05-30-lcd1-solver-design.md` for the design.
