# LCD1 Solver — moved to its own repository

The offline LCD1 exam solver that used to live here is now a standalone project so
others can clone and use it:

- **GitHub:** https://github.com/MadsRudolph/lcd1-solver
- **Local clone:** `C:\Users\Mads2\lcd1-solver`

Clone and run:

```bash
git clone git@github.com:MadsRudolph/lcd1-solver.git
cd lcd1-solver
pip install -r requirements.txt
python run.py
```
